# Contribuir

Gracias por mejorar el SDK VEXT de Vectora.

## Flujo

Los cambios se realizan en el monorepo de Vectora mientras el SDK se prepara para separarse en el futuro. Abre una issue para cambios grandes de API, usa Conventional Commits e incluye pruebas o una validación clara.

## Comprobaciones locales

Ejecuta `npm run check` dentro de `vext-sdk`. No confirmes `dist`, credenciales, tokens ni datos privados generados. Mantén la compatibilidad de las APIs públicas o documenta la migración.

## Pull requests

Describe el comportamiento visible, el impacto de seguridad y las notas de migración. Los revisores deben poder ejecutar los comandos documentados en un checkout limpio.
