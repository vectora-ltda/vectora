# Security

Do not disclose vulnerabilities in public issues. Send a private report through the Vectora security process and include the affected package version, a minimal reproduction, and impact. Never include secrets or personal data.

The SDK sandbox is a boundary for browser contributions, not a replacement for host-side validation. Keep trust, capability, origin, and message validation in the host.
