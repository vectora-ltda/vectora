# Segurança

Não divulgue vulnerabilidades em issues públicas. Envie um relato privado pelo processo de segurança do Vectora com a versão afetada, reprodução mínima e impacto. Nunca inclua segredos ou dados pessoais.

O sandbox do SDK é uma fronteira para contribuições do navegador, não substitui a validação no host. Confiança, capabilities, origem e mensagens devem ser validadas pelo host.
