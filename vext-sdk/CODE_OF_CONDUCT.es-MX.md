# Código de conducta

## Compromiso

Queremos que el SDK VEXT sea acogedor, respetuoso y seguro para todos.

## Comportamiento esperado

Usa lenguaje constructivo, respeta distintos contextos y centra los comentarios en el trabajo. No se aceptan acoso, discriminación, amenazas ni publicación de información privada.

## Cumplimiento

Reporta problemas en privado mediante los canales de seguridad o soporte. Los mantenedores pueden retirar contenido o restringir la participación para proteger a la comunidad.
