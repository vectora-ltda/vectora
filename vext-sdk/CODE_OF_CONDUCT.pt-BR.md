# Código de conducta

## Compromisso

Queremos que o SDK VEXT seja acolhedor, respeitoso e seguro para todos.

## Comportamento esperado

Use linguagem construtiva, respeite diferentes contextos e concentre o feedback no trabalho. Assédio, discriminação, ameaças e publicação de informações privadas não são aceitos.

## Aplicação

Relate problemas em privado pelos canais de segurança ou suporte. Os mantenedores podem remover conteúdo ou restringir participação para proteger a comunidade.
