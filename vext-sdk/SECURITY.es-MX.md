# Seguridad

No divulgues vulnerabilidades en issues públicas. Envía un informe privado mediante el proceso de seguridad de Vectora con la versión afectada, una reproducción mínima y el impacto. Nunca incluyas secretos ni datos personales.

El sandbox del SDK es una frontera para contribuciones del navegador, no sustituye la validación del host. El host debe validar confianza, capacidades, origen y mensajes.
