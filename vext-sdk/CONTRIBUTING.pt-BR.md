# Contribuindo

Obrigado por melhorar o SDK VEXT do Vectora.

## Fluxo

As mudanças são feitas no monorepo do Vectora enquanto o SDK é preparado para uma separação futura. Abra uma issue para mudanças grandes de API, use Conventional Commits e inclua testes ou uma nota clara de validação.

## Verificações locais

Execute `npm run check` em `vext-sdk`. Não versione `dist`, credenciais, tokens ou dados privados gerados. Preserve compatibilidade das APIs públicas ou documente a migração.

## Pull requests

Descreva o comportamento visível, o impacto de segurança e as notas de migração. Os revisores devem conseguir executar os comandos documentados em um checkout limpo.
