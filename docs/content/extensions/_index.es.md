Las extensiones de Vectora se empaquetan como artefactos `.vext` firmados. Esta sección cubre todo el ciclo, desde la autoría y la compilación hasta la verificación de confianza, instalación y ejecución aislada.

## Contenido

- [Formato y seguridad VEXT](vext.es.md)
- [Tutorial de backend Python](vext-python.es.md)
- [Tutorial de frontend TypeScript](vext-typescript.es.md)
- [Tutorial de publicación y rollback](vext-publish.es.md)

El SDK se desarrolla actualmente dentro del monorepo de Vectora y se publica como `@vectora/extension-sdk`. Se moverá a un repositorio dedicado en una fase futura.
