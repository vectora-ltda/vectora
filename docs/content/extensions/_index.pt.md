As extensões do Vectora são empacotadas como artefatos `.vext` assinados. Esta seção cobre todo o ciclo, desde autoria e build até verificação de confiança, instalação e execução isolada.

## Conteúdo

- [Formato e segurança VEXT](vext.pt.md)
- [Tutorial de backend Python](vext-python.pt.md)
- [Tutorial de frontend TypeScript](vext-typescript.pt.md)
- [Tutorial de publicação e rollback](vext-publish.pt.md)

O SDK é desenvolvido atualmente dentro do monorepo do Vectora e publicado como `@vectora/extension-sdk`. Ele será movido para um repositório dedicado em uma fase futura.
