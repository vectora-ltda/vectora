## 0.3.0 — release-line contents

The `release/0.3` line brings canonical contracts, AgentRun and its event ledger, DAG/Kanban execution, executable Plan Mode, verification and replay, memory and Context Graph, policy/egress, and workbenches. Configurable HITL and Decision Models are in PR [#404](https://github.com/vectora-ltda/vectora/pull/404), stacked on this line.

This page documents the planned 0.3.0 composition. Treat the version as published only when the repository provides its tag and release artifacts. See [What's new in 0.3](../guides/release-0.3) and the [roadmap](https://vectora.company/roadmap) for status and usage instructions.
